# Не покрыто переводом

Список строк интерфейса, которые остаются английскими, и причины. Обновляется
вместе со словарём.

## Нужны правила или другая механика

| Где | Строка | Почему |
|---|---|---|
| Меню строки треда | `Notify parent, Off` | Источник не найден ни во встроенных плагинах BB 0.49.0, ни в Tasks/Spaces; вероятно, локальный плагин. Пункт не входит в список встроенных подписей меню. |
| Подсказки уровня уведомлений | `Limited by a parent thread`, `Limited by an ancestor thread` | Переведены в словаре и покрыты тестом на макете, но вживую не проверены: нужен тред, ограниченный родителем. |
| Боковая панель | `Collapse <имя> section`, `<имя> actions`, `New thread in <имя>` | Подписи собираются из шаблона с названием проекта или пространства. Словарь сопоставляет строки целиком и не умеет шаблоны с пользовательскими данными. |
| Боковая панель | подсказка перетаскивания dnd-kit (`To pick up a draggable item…`) | Скрытый `display: none` текст для экранных читалок. Исходная строка многострочная, а словарь не принимает ключи с переносами. |
| Боковая панель | `Claude Code`, `Codex` на значках провайдера | Имена собственные, не переводятся. |
| Тред | `Parent`, `Message from`, `Worked for 4m 10s`, `TEXT` | Область сообщений и ленты защищена намеренно: там текст агента и пользователя. |
| Поле ввода | `Ask for a follow-up. @ to mention…` | Подсказка внутри редактора; он перерисовывает атрибут на любую правку. |
