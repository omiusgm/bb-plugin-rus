# Не покрыто переводом

Список строк интерфейса, которые остаются английскими, и причины. Обновляется
вместе со словарём.

## Нужны правила или другая механика

| Где | Строка | Почему |
|---|---|---|
| Меню строки треда | `Notify parent, Off` | Источник не найден ни во встроенных плагинах BB 0.49.0, ни в Tasks/Spaces; вероятно, локальный плагин. Пункт не входит в список встроенных подписей меню. |
| Подсказки уровня уведомлений | `Limited by a parent thread`, `Limited by an ancestor thread` | Переведены в словаре и покрыты тестом на макете, но вживую не проверены: нужен тред, ограниченный родителем. |
| Боковая панель | `Collapse <имя> section`, `<имя> actions`, `New thread in <имя>` | Подписи собираются из шаблона с названием проекта или пространства. Словарь сопоставляет строки целиком и не умеет шаблоны с пользовательскими данными. |
| Боковая панель, «Свой вариант» | `Collapse <раздел> section`, `Expand <раздел> section`, `New thread in <раздел> section`, `<раздел> section actions`, `<раздел> — contains a thread open in split` | Подписи со словом из названия пользовательского раздела; видны только экранным читалкам. Для встроенных «Треды» и «Закреплено» переведены целыми строками. Ждут механики шаблонов. |
| Боковая панель, «Свой вариант» | `aria-label` полей ввода: `Section name`, `Thread name`, `Project name` | Поля ввода вне охвата переводчика: их подписи не видны, правило пришлось бы открывать для `input` внутри плагина. |
| Боковая панель, «Свой вариант» | Подсказка и объявления перетаскивания dnd-kit (`To pick up a draggable item…`, `Picked up draggable item …`, `Draggable item … was dropped over …`) | Подсказка скрыта (`display: none`) и многострочная; объявления — живая область для читалок, с внутренними id вместо названий. Видимых подписей при перетаскивании нет: плавает только название треда. |
| Боковая панель, «Свой вариант» | Всплывающие ошибки `Failed to move thread.`, `Failed to create section.`, `Failed to remove section.` | Всплывашки sonner; без сбоя сервера не вызвать, а ломать данные владельца нельзя. Строки в словаре есть, область для всплывашек не заведена. |
| Боковая панель, «Свой вариант» | Подменю «Переместить в раздел» (список разделов и пункт `Threads`) | Названия разделов — данные пользователя, подменю остаётся английским намеренно. |
| Меню строки треда, диалог переименования | Описание `Choose a new name for this <вид>.` | Собрано из трёх текстовых узлов вокруг слова вида; переведено как «Новое название. Объект: раздел.» Ключи `section`, `thread`, `project` работают только в этом диалоге. На десктопе с мышью диалог не открывается (там правка на месте); живьём не видел. |
| Боковая панель | подсказка перетаскивания dnd-kit (`To pick up a draggable item…`) | Скрытый `display: none` текст для экранных читалок. Исходная строка многострочная, а словарь не принимает ключи с переносами. |
| Боковая панель | `Claude Code`, `Codex` на значках провайдера | Имена собственные, не переводятся. |
| Боковая панель | `Codex and Claude Code updates available`, `N plugin updates available` | Шаблон с названиями и числом, словарь не умеет (см. строку про шаблоны выше). |
| Тред | `Parent`, `Message from`, `Worked for 4m 10s`, `TEXT` | Область сообщений и ленты защищена намеренно: там текст агента и пользователя. |
| Поле ввода | `Ask for a follow-up. @ to mention…` | Подсказка внутри редактора; он перерисовывает атрибут на любую правку. |
| Композер, окно модели | `Ultracode`, подсказка строки Fast mode (`Faster responses on supported Opus models…`), список «Больше моделей» (раскрытый) | `Ultracode` — название режима, оставлено. Подсказка приходит от провайдера. Раскрытый список не открывал. |
| Композер | Заголовок `Permission mode` в меню режима доступа; подсказки `Permission mode: …`, `Claude Code: Opus 5 · Medium reasoning`; `Context window 56% used`; `N active child threads` | Шаблоны с данными. |
| Композер | Меню «Параметры отправки» | Пусто, пока поле ввода пустое; пункты не видел. |
| Композер, меню «+» | Подпись самого меню `Prompt actions` | Метка меню остаётся английской (читают только экранные читалки). |
| Меню проекта | Подпись `<проект> actions` и скрытый текст выбранной сортировки `, descending. Sort ascending` | Название проекта внутри строки, текст из нескольких узлов. `aria-label` выбранной сортировки переведён целиком. |
| Шапка | `Open workspace in Xcode (⌘ O)` | Шаблон с названием приложения. Вне задачи (не боковая панель и не композер). |
| Подсказки с горячими клавишами | Формы для Ctrl вместо ⌘ у `Search threads`, `Settings`, `Show right panel`, `Provider, model and reasoning`; `Hide right panel (⌘ J)` | Добавлены только формы для Mac, которые видел вживую. |

## Закрыто в этой правке

- Меню проекта и его подменю «Упорядочить», «Сортировать по», «Фильтр».
- Плашка «Активные дочерние треды».
- Окно выбора модели (заголовки, уровни рассуждения, «Быстрый режим», «Продолжить в новом треде», поиск). Названия моделей и провайдеров не тронуты.
- Из прошлого списка закрыть нечего: механики шаблонов с названием по-прежнему нет, подсказка перетаскивания
  в живом интерфейсе осталась английской (проверено). `Notify parent, Off` и `Limited by a parent thread` в этой
  правке не перепроверял.
