# Русский для bb

Независимый плагин перевода интерфейса [bb](https://getbb.app) на русский.
В словаре 2056 переводов, включая плагины Tasks и Spaces, меню треда и боковую панель. Кнопки, меню и подписи переведены по единому глоссарию: «тред», «ответ»,
«компьютер», «окно чата». Worktree и workflow сохраняют свои названия.

## Установка

Нужен bb **0.49.0 или новее**, Plugin SDK **0.6.132 или новее**.

```sh
bb plugin install git:https://github.com/omiusgm/bb-plugin-rus.git@v1.0.2
```

При установке bb покажет источник и запросит подтверждение. Другой активный
русификатор нужно отключить, чтобы два переводчика не меняли одни и те же
элементы. Для исходного плагина с ID `ru`:

```sh
bb plugin disable ru
```

ID этого плагина — `rus`. Переключатель языка находится в настройках bb,
в разделе «Русский интерфейс». Настройка сохраняется отдельно в каждом
браузере. Перезагрузка страницы для переключения не нужна.

## Границы перевода

Переводятся точные совпадения из встроенного словаря внутри элементов
управления: кнопок, меню, подписей и диалогов, а также в проверенных блоках
настроек BB. Неизвестные строки остаются
английскими. Это частичная локализация, а не гарантия перевода всего BB.

Движок исключает сообщения, код, редакторы, терминалы, значения полей ввода и известные
области пользовательских названий. Произвольный текст страницы не переводится.
Защита зависит от разметки BB: после обновлений приложения нужна проверка.
Поэтому редкие или неоднозначные элементы могут оставаться английскими.

Подсказки отдельных штатных полей поиска и настроек переводятся отдельно
от их значений. Пользовательский ввод и сохранённые значения не читаются.

При выключении плагин возвращает исходный текст, если BB с тех пор его
не изменил. Значения полей ввода не читаются и не меняются.

## Данные

В плагине нет телеметрии, сетевых запросов и сбора непереведённых строк.
Словарь встроен в пакет. В localStorage записывается только переключатель
языка. BB самостоятельно скачивает исходники и зависимости при установке.

## Правка словаря

Добавить полную английскую подпись и перевод в `dict/ru.json`, затем проверить
[глоссарий](dict/GLOSSARY.md). Обрывки предложений, код и пользовательские
названия добавлять не нужно.

```sh
npm ci
npm run check:dict
npm test
npm run typecheck
npm run build
```

Проверки релиза: проверка словаря и ссылок на исходники, тесты, проверка типов
и сборка. Результаты живого аудита и снимки «до/после» —
[в отчёте v1.0.1](docs/coverage-v1.0.1.md).

Для локальной установки после сборки: `bb plugin install .`.
